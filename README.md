# HPC Swarm

Lightweight HPC intelligence swarm.

## Features

- Markdown-defined agents
- Parallel scout execution
- Dynamic topic discovery
- Self-modifying swarm evolution
- Local markdown memory
- Single-node execution
- OpenRouter support

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Set environment variables:

```bash
export OPENROUTER_API_KEY=...
```

## Run

```bash
python run.py
```

## Philosophy

Markdown is the API.
Humans and agents both evolve the system.
